# Videos

One folder per video, created by `make-video` at the brief-summary stop:

```
videos/<ID>-<slug>/
  brief.md          brief summary (approved, dated) · asset map · gap decisions · storyboard · publish block · checks
  composition/      the Hyperframes project written by build-video (index.html, assets/)
  output/           <ID>.mp4, <ID>.jpg (poster, also frame 0), caption.txt   — ignored by git
```

Status lives in `../BACKLOG.md`. Nothing in `brief.md` below the brief summary is written until the summary is approved and every gap has a decision.
